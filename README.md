Практические задания: Динамические массивы в языке C
Описание
Набор заданий по работе с динамической памятью в C. Изучаем функции malloc, calloc, realloc, free и операции с массивами.

Содержание
Задание 1. Создание динамического массива
Запрос размера массива у пользователя

Выделение памяти под массив int с помощью malloc

Заполнение массива с клавиатуры

Вывод массива на экран

Задание 2. Использование calloc
Выделение массива из n элементов с помощью calloc

Вывод значений элементов (инициализированы нулями)

Задание 3. Поиск элементов
Создание динамического массива

Функции поиска:

Максимального элемента

Минимального элемента

Суммы всех элементов

Задание 4. Изменение размера массива (realloc)
Создание массива из n элементов

Увеличение размера до m элементов с помощью realloc

Ввод новых элементов

Вывод обновленного массива

Уменьшение размера массива

Задание 5. Удаление элемента
Создание динамического массива

Удаление элемента по заданному индексу

Сдвиг последующих элементов

Уменьшение размера массива через realloc

Задание 6. Вставка элемента
Создание динамического массива

Вставка элемента в заданную позицию

Увеличение размера массива

Сдвиг элементов

Задание 7. Массив структур (динамический)
Структура Student:

char name[50]

int age

Задачи:

Выделение динамического массива структур

Заполнение данных студентов

Вывод всех студентов

Поиск самого старшего студента

Задание 8. Динамический список чисел с меню
Функционал:

Добавление элемента

Удаление элемента

Вывод списка

Изменение размера массива

Интерфейс:

Меню с циклом выбора действий (while + switch)

Требования к реализации
Всегда проверять результат malloc/calloc/realloc на NULL

Освобождать память с помощью free() в конце программы

Обработка ошибок ввода/вывода

Комментарии к основным блокам кода

Структура файлов
