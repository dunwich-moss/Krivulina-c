Описание
Лабораторная работа посвящена изучению структур в языке C: объявление, вложенные структуры, указатели, массивы структур, функции, enum и union.

Цель работы
Изучить объявление и использование структур, вложенные структуры, указатели на структуры, массивы структур, передачу структур в функции, перечисления (enum) и объединения (union).
