# Менеджер персональных данных с файлами и библиотеками C

## 🎯 Цель проекта
Создать консольную программу для управления базой данных людей с возможностью работы в памяти, сохранения/загрузки из файлов и интерактивным меню через указатели на функции.

## 📋 Требования к программе

### Структура данных
```c
struct Person {
    char name[MAX_NAME];    // Имя (строка)
    int age;                // Возраст (целое число)
    float height;           // Рост (float)
    int birth_year;         // Год рождения (int)
};
```

### Обязательные функции
- ✅ **Добавление записи** (ввод с клавиатуры)
- ✅ **Вывод всех записей**
- ✅ **Сортировка** (по имени, по возрасту)
- ✅ **Статистика** (средний возраст, максимальный рост)
- ✅ **Сохранение** в бинарный файл (`fwrite/fread`)
- ✅ **Загрузка** из бинарного файла
- ✅ **Поиск** по имени или диапазону возраста
- ✅ **Выход**

### Технические требования
| Требование | Статус |
|------------|--------|
| Динамическая память (`malloc/realloc/free`) | ✅ |
| Указатели на структуры | ✅ |
| Указатели на функции для меню (без `if/switch`) | ✅ |
| Стандартные библиотеки C (строки, память, даты, математика) | ✅ |
| Проверка ввода (имя - буквы, возраст/рост > 0) | ✅ |
| Работа с бинарными файлами + проверка ошибок | ✅ |

### Дополнительные возможности (для повышенной оценки)
- 🟡 Вычисление реального возраста (`time.h`)
- 🟡 Универсальный вывод через `_Generic`
- 🟡 Сохранение в текстовый файл
